# 族群｜利基型記憶體(Legacy Memory)

> 索引：[[族群輪動索引_AI供應鏈]]｜代表股：[[個股_晶豪科_3006]]
> 資料日 2026-09-03(taiwan-stock MCP 官方；產業論點來源見下)。非投資建議。

## 一句話定位
**大三家(三星/美光/SK,佔 ~95%)把產能轉向高價 HBM/DDR5 → 利基記憶體(DDR3/DDR2、NOR Flash、SLC NAND)結構性缺貨、ASP 飆漲。** 需求來自工控/醫療/HDD/IP cam/消費——**與 AI datacenter「不同引擎」,是分散主題**。

## 論點來源與性質
- 來源:X @aleabitoreddit(Serenity)2026-08-30/31 兩篇 thread(作者**自述有部位**,多方立場);我用 taiwan-stock 官方數據交叉驗證。
- 性質:**景氣循環 + 缺貨漲價**價值題材,非結構性成長;波動大。
- **產業佐證(2026-09 SEMICON Taiwan)**:美光總裁/CTO **Scott DeBoer** 公開表示記憶體供不應求、將**持續數年**——與本族群缺貨漲價論點一致。【事實】來源:[INSIDE](https://www.inside.com.tw/article/42273-micron-deboer-semicon-taiwan-2026-hbm-thermal-tokenomics)。

## 核心邏輯(作者)
1. 利基供給萎縮(大廠轉 HBM),缺貨延續(作者看至 2027)。
2. 晶豪科 ESMT Q2 blended **ASP +105~113% QoQ**、7 月淨利爆量。
3. **需求無彈性**:DDR3 佔終端 BOM 僅幾美元 → 客戶寧付漲價也不重新設計/認證 → 漲價直灌淨利。
4. 供給端力積電 PSMC 晶圓漲價 ~100%(2H26)可轉嫁。

## 我的判斷
- **認同**:缺貨漲價邏輯真實、有雙印證;「BOM 佔比低→無彈性」解釋 ASP 翻倍的可持續性,聰明。
- **保留**:(1)循環峰值,低 P/E 恐為 **cyclical trap**;(2)股價已大漲、外資高檔鉅賣,**基本面驗證≠現在該追**(同「被動元件/國巨」教訓,純文字類比不直連);(3)供給端力積電外資狂賣。
- **結論**:值得追蹤,**不宜高檔爆量+外資鉅賣時追**;理想進場=外資止賣 + Q3/H2 漲價延續獲確認。
