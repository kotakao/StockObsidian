# 連接｜ASIC 需求外溢載板與封裝

> 中繼點筆記(說明連結):集中說明「CSP 自研 ASIC/XPU」與載板、材料、光互連族群的關聯,讓相關族群連到本筆記、而非彼此直連。**不連索引**。非投資建議。

## 一句話
CSP 自研 ASIC/XPU 狂潮(Broadcom AI、AWS Trainium、Google TPU、Nvidia 認購聯發科 CB 等)使 XPU 出貨放大 → **載板餅、先進封裝、光互連需求同步↑(ASIC↑ = 載板餅↑)**。

| 環節 | 機制 | 對應族群 |
|---|---|---|
| ASIC 設計/量產 | XPU 需求爆發(世芯/創意/聯發科) | [[族群_ASIC設計服務]] |
| ABF 載板 | 大尺寸/高層數載板用量↑ | [[族群_ABF載板]] |
| PCB / CCL 材料 | 高速板 + CCL 用量↑ | [[族群_PCB與CCL]] |
| 光互連 | XPU 機櫃仍需 CPO/光模組(同一 AI 鏈) | [[族群_光通訊與CPO]] |
