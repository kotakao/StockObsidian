# 台股研究能力養成手冊
## ——從資料取得到買賣決策的完整自學指南

> **這本手冊是什麼**：把「量化分析師 + 產業研究員 + 輪動策略研究員」的分析流程，拆解成一個沒有金融背景的人可以逐步自學、自行執行的操作手冊。
> **這本手冊不是什麼**：不是投資建議、不是保證獲利的方法、不是速成秘笈。它教的是「如何取得資訊、如何判讀、如何防守」，判斷與盈虧責任永遠在你自己。

---

# 第 0 章｜先建立心智模型：分析師腦中的那條推論鏈

所有分析（包括你看過的 AI 分析）本質上都在走同一條鏈：

```
技術趨勢 → 產業需求 → 供應鏈瓶頸位置 → 公司獲利動能 → 法人資金行為 → 族群輪動 → 股價反應
```

用白話拆解每一環你要回答的問題：

| 環節 | 你要回答的問題 | 對應本手冊章節 |
|---|---|---|
| 技術趨勢 | 現在世界在做什麼大事？（例：AI 伺服器功耗暴增） | 第 5 章 |
| 產業需求 | 這件大事需要買什麼東西？（例：更多電源、散熱、記憶體） | 第 5 章 |
| 供應鏈瓶頸 | 哪個環節「不夠賣」？缺貨的人才有漲價權 | 第 5 章 |
| 獲利動能 | 缺貨有沒有真的變成營收和毛利率？ | 第 2 章 |
| 法人行為 | 大資金有沒有在買？誰在買？ | 第 3 章 |
| 族群輪動 | 資金現在在哪一棒？下一棒可能是誰？ | 第 5 章 |
| 股價反應 | 現在的價格反映到哪了？位階高不高？ | 第 4 章 |

**三個貫穿全書的紀律**（比任何公式都重要）：

1. **區分「事實」與「推論」**：營收數字是事實，「營收會繼續成長」是推論。寫筆記時強迫自己標註，久了你會發現自己大部分的虧損來自把推論當事實。
2. **每個判斷都要有「否證條件」**：買進前先寫下「出現什麼訊號代表我錯了」。沒有否證條件的判斷不是分析，是信仰。
3. **股票不知道你的成本價**：續抱或賣出的依據是「當初的論點還成不成立」，不是「回本了沒」。

# 第 1 章｜資料來源地圖：去哪裡拿訊號（全部免費）

## 1.1 官方一手資料（最可信，養成直接查原始資料的習慣）

| 資料 | 網站 | 你會用到的功能 |
|---|---|---|
| 月營收、財報、重大訊息、法說會公告 | 公開資訊觀測站 mops.twse.com.tw | 「營運概況→每月營收」「重大訊息」「法說會」專區 |
| 大盤與個股三大法人買賣超、融資融券 | 證交所 www.twse.com.tw（上市）、櫃買中心 www.tpex.org.tw（上櫃） | 「交易資訊→三大法人」每日下午約 4~5 點更新 |
| 股東結構、董監持股、質押 | 公開資訊觀測站 + 集保結算所（股權分散表） | 觀察大股東是否在賣自家股票 |

**關鍵日曆（背起來）**：
- 每月 **10 日前**：所有上市櫃公司公布上月營收（月營收行情的來源）
- **5/15、8/14、11/14**：Q1、Q2、Q3 財報截止日；**3/31**：年報
- 法說會：不定期，公開資訊觀測站「法人說明會」專區可查未來時程
- 每日盤後：三大法人買賣超公布

## 1.2 整理型網站（把官方資料視覺化，省你時間）

| 網站 | 強項 | 建議用法 |
|---|---|---|
| Goodinfo!（goodinfo.tw） | 個股所有歷史數據最齊：營收、財報、法人、融資、殖利率 | 你的「個股體檢中心」，看單一公司先來這 |
| 財報狗（statementdog.com） | 財報視覺化 + 概念股分類（例：BBU 概念股有哪些） | 建供應鏈地圖時查「XX 概念股」 |
| 玩股網 / HiStock / CMoney | 法人買賣超排行、族群漲跌幅 | 每天看「今天錢流去哪個族群」 |
| 鉅亨網 / MoneyDJ / 經濟日報 | 產業新聞、法說會報導、漲價消息 | 追蹤「漲價信」與訂單新聞 |
| TradingView（tw.tradingview.com） | 免費看 K 線、畫均線、看美股台股 | 你的看圖工具 |

## 1.3 產業訊號源（判斷輪動的上游情報）

- **報價類**：TrendForce（記憶體/面板報價新聞）、各財經媒體的「漲價」關鍵字新聞。缺貨漲價 = 本輪行情最強的點火器。
- **國際連動**：費城半導體指數（SOX）、NVIDIA/台積電 ADR、美光/博通財報——台股電子股是美股的下游，美股法說會常常是台股族群行情的引信。
- **法說會逐字內容**：公司官網投資人專區（IR）通常有簡報檔與影音。法說會是「公司自己說的展望」，比任何新聞轉述可信。
- **關鍵字追蹤法**：在 Google 新聞設定追蹤詞，例如「漲價 通知」「調漲 報價」「接單出貨比」「訂單能見度」「供不應求」。每天花 10 分鐘掃一遍，你就擁有了輪動雷達的雛形。

## 1.4 一個重要的提醒：資訊的可信度階層

```
第一層（最可信）：公司公告、財報、月營收 → 這是事實
第二層：法說會管理層發言 → 公司的自我陳述，有立場但可追責
第三層：券商/投顧報告、外資目標價 → 專業推論，但有利益立場
第四層：財經新聞轉述 → 常有斷章取義
第五層（最不可信）：社群、群組、KOL 點名 → 只能當「市場情緒溫度計」，不能當依據
```
新手最常見的錯誤是用第五層資訊做決策、用第一層資訊馬後炮。順序要倒過來。

# 第 2 章｜基本面最小工具箱：看懂一家公司只需要這幾個數字

不需要會計背景。以下公式由淺入深，前四個就能過濾掉八成的地雷。

## 2.1 營收動能（最即時的基本面訊號，每月更新）

- **月營收年增率 YoY** = (本月營收 − 去年同月營收) ÷ 去年同月營收
  - 為什麼看 YoY 不看 MoM：排除季節性（例：每年 Q4 都是旺季）。
  - 判讀：YoY 由負轉正 = 轉機訊號；連續多月 YoY 加速 = 成長動能；YoY 增幅逐月縮小 = 動能減弱的早期警訊（股價常領先反應）。
- **累計營收 YoY**：今年至今 vs 去年同期，過濾單月波動。
- 資料來源：公開資訊觀測站或 Goodinfo 個股頁「每月營收」。

## 2.2 獲利品質三兄弟（每季更新）

- **毛利率** = 毛利 ÷ 營收。看「方向」比看絕對值重要：漲價題材是否為真，就看毛利率有沒有跟著漲價往上走。營收大增但毛利率下滑 = 可能在賠錢搶單。
- **營業利益率** = 營業利益 ÷ 營收。扣掉管銷研費用後的本業賺錢能力。
- **EPS（每股盈餘）** = 稅後淨利 ÷ 流通股數。注意區分「本業獲利」與「業外一次性收益」（賣土地、匯兌），Goodinfo 損益表可以看出來。

## 2.3 估值三把尺（判斷「貴不貴」）

- **本益比 PE** = 股價 ÷ 每股盈餘（EPS）
  - 直覺翻譯：用現在的獲利水準，幾年回本。
  - 陷阱一：用「過去四季 EPS」算的 PE 對成長股會失真，市場買的是未來。
  - 陷阱二：景氣循環股（記憶體、面板、航運）在「PE 最低的時候往往是高點」——因為獲利在頂峰。循環股要反過來看：低 PE 警惕、高 PE（或虧損）反而可能在谷底。這是新手最容易套牢的認知盲點。
- **股價淨值比 PB** = 股價 ÷ 每股淨值。適合看金融股與景氣循環股的歷史區間位置。
- **殖利率** = 每股現金股利 ÷ 股價。防守型指標，高殖利率提供下檔緩衝，但要確認股利有獲利支撐（盈餘分配率 < 100%）。

## 2.4 進階但值得早點認識的概念

- **接單出貨比（BB ratio）** > 1 代表接單多於出貨、訂單能見度好。公司法說會或新聞會揭露。
- **存貨天數**：存貨 ÷ 每日銷貨成本。存貨突然暴增 + 營收沒跟上 = 賣不動的警訊；漲價循環中廠商刻意囤低價庫存則是利多，要搭配產業情境判讀。
- **ROE（股東權益報酬率）** = 稅後淨利 ÷ 股東權益。長期持有看這個，>15% 且穩定是好生意的特徵。

## 2.5 十分鐘個股體檢 SOP（每次想買一檔股票前必做）

1. Goodinfo 查月營收：近 12 個月 YoY 趨勢是加速、持平還是減速？
2. 查近 4 季毛利率：方向朝上還是朝下？
3. 查 EPS：本業賺的還是業外撐的？
4. 查 PE：跟它自己過去 5 年的區間比（不是跟別人比），現在在區間的高檔還是低檔？它是成長股還是循環股？
5. 查現金股利政策：連續配息幾年？
6. **寫下一句話結論 + 標註這是事實還是推論。** 寫不出來就不要買。

# 第 3 章｜籌碼面入門：看懂「大錢」在做什麼

## 3.1 三大法人是誰、行為模式差在哪

| 法人 | 是誰 | 行為特徵 | 對你的意義 |
|---|---|---|---|
| 外資 | 國外機構資金 | 部位大、偏好權值股、動作連續（一買買很多天） | 決定大盤方向；外資連續大賣時大盤很難漲 |
| 投信 | 國內基金公司 | 偏好中小型股、有「季底作帳」慣性（3/6/9/12 月底衝績效） | 中小型飆股的主要推手；投信連續買超常是波段起點 |
| 自營商 | 券商自己的錢 | 短進短出、含避險部位 | 參考價值最低，可先忽略 |

## 3.2 怎麼看才有意義：連續性 > 單日

- 單日買賣超是雜訊。有意義的訊號是：**連續 3~5 日以上同方向**、且金額/張數相對該股日均量顯著。
- 個股層級：Goodinfo 個股頁「法人買賣」可看每日與累計。重點組合：
  - **投信連續買超 + 月營收轉強** = 波段行情的經典起手式
  - **外資與投信同買** = 最強格局
  - **股價創高但法人轉賣** = 出貨警訊（誰在買？散戶）
- 大盤層級：每天收盤後看三大法人合計買賣超金額。外資連續每日賣超數百億時，就是「防守模式」的訊號。

## 3.3 融資餘額：散戶熱度計

- 融資 = 借錢買股票，主要是散戶行為。
- **融資餘額隨股價上漲快速膨脹** = 行情越來越擁擠、洗盤時跌得越兇（借錢的人被迫停損會產生連鎖賣壓）。
- 個股融資使用率 > 50~60%，代表籌碼很「浮」，遇利空容易多殺多。
- 查詢：Goodinfo 或證交所「融資融券」。

## 3.4 其他值得看的籌碼訊號

- **董監與大股東持股變化**（公開資訊觀測站）：內部人連續申報轉讓是長期警訊。
- **股權分散表**（集保）：千張大戶持股比例上升 = 籌碼集中（偏多）；下降 = 大戶在出貨給散戶。
- **注意/處置股公告**（證交所）：一個族群裡處置股大量出現，通常是該波行情過熱的末段特徵。

# 第 4 章｜技術面最低限度：不預測，只防守

技術分析流派眾多，新手只需要「位階判斷」與「危險訊號辨識」兩個功能。目的不是抓買點，是**避免買在高點、以及套牢前及早離場**。

## 4.1 均線：判斷趨勢與位階的尺

- **5 日線**＝短線多空氣氛；**20 日線（月線）**＝波段生命線；**60 日線（季線）**＝中期趨勢分界。
- 最低限度的用法：
  - 股價在季線之上且季線向上 = 中期多頭，回檔是整理；跌破季線且季線走平下彎 = 中期趨勢轉弱，不要凹單。
  - **乖離率** =（股價 − 均線）÷ 均線。股價離月線 +20%、+30% 以上叫「正乖離過大」——這就是「買在高點」的量化定義。看到很想追的股票，先算這個數字，通常能救你一命。

## 4.2 量價關係：資金的表情

- 上漲 + 溫和放量 = 健康；上漲 + 爆天量 = 高檔換手劇烈，未必馬上跌但風險升高。
- **爆量長上影線**（盤中衝高、收盤跌回、成交量暴增）出現在大漲一段之後 = 主力趁熱倒貨的經典型態，短線務必提高警覺。
- 下跌 + 量縮 = 賣壓漸竭；下跌 + 放量 = 恐慌或有人堅決出場，別急著接刀。

## 4.3 三個「不要」

1. **不要**背誦上百種 K 線型態，先把均線位階 + 量價異常看熟。
2. **不要**相信任何人（包括 AI）給你的精確支撐壓力價位，除非他能說明計算依據。你自己可以用「前波高低點、整理區間上下緣、均線位置」建立粗略參考。
3. **不要**用技術面對抗基本面惡化：月營收連續衰退的股票，「技術面止跌」大多是反彈不是反轉。

# 第 5 章｜產業與輪動分析：從「一檔股票」升級到「一盤棋」

這是整套能力裡最有價值、也最少人做的部分。

## 5.2 第一步：建立供應鏈地圖（一次性功課，做一次受用一年）

以任何一個熱門產業為例（AI 伺服器最適合練習）：

1. 到財報狗搜「AI 伺服器概念股」「散熱概念股」「BBU 概念股」等分類頁，把公司名單抄下來。
2. 到每家公司的公開年報（公開資訊觀測站→電子書）看「營業項目與產品組合」，確認它**實際營收裡該產品佔多少 %**——這一步就是在區分「真受惠」與「概念沾邊」。營收占比 <10% 的題材股，行情來時漲得兇，退潮時跌得更兇。
3. 畫成一張圖（手畫即可）：上游材料 → 中游零組件 → 下游系統組裝，每個環節寫上 2~3 家代表公司。
4. 每季用新聞與法說會更新一次。

## 5.2 輪動的四個可重複規律（觀察 checklist）

從歷史行情可歸納，資金在族群間移動時有慣性：

- **規律一：點火器是「漲價/缺貨/新規格」**。追蹤方法：第 1 章的關鍵字雷達。看到某族群出現第一封漲價通知，把整個族群加入觀察清單。
- **規律二：資金沿供應鏈瓶頸移動**。問自己：現在最缺的是什麼？缺貨解決後，下一個卡住的環節是誰？（例：晶片夠了缺散熱→散熱夠了缺電源→電源要升級缺功率元件）
- **規律三：每一棒的起點是「低基期 + 可驗證催化劑」，終點是「爆量上影 + 處置股 + 人人都在講」**。當計程車司機和家族群組都在討論某族群時，你要做的是檢查出場條件，不是進場。
- **規律四：看誰在主導**。投信主導的中小型行情走得久；純散戶題材行情（融資暴增、法人沒買）通常一~兩週就結束。

## 5.3 每週輪動觀察 SOP（每週日 30 分鐘）

1. 打開族群漲跌幅排行（CMoney/玩股網），記錄本週最強與最弱的 3 個族群。
2. 對最強族群問三個問題：它是第幾週上榜？（第 1~2 週=初升段可研究；第 4 週以上=留意末段）催化劑是什麼？（漲價？營收？純題材？）法人有沒有買？
3. 對「還沒漲但邏輯上該輪到」的族群建立觀察清單，等待它自己的催化劑（月營收、法說會、漲價信）出現。
4. 寫 5 行週記：本週資金在哪、我認為下週會在哪、否證條件是什麼。**這份週記三個月後回看，就是你最好的老師。**

# 第 6 章｜決策與風控：讓你「輸得起」的系統

會分析不等於會賺錢，中間差一套決策紀律。這章是整本手冊裡最能減少「買在高點被套牢」的部分。

## 6.1 進場前檢查表（缺一項就不進場）

```
□ 論點：我買它的理由是什麼？（一句話，標註事實/推論）
□ 催化劑：未來 1~3 個月有什麼可驗證的事件？（月營收、法說、漲價）
□ 位階：股價離月線乖離多少？族群是第幾週的行情？
□ 籌碼：法人在買還是散戶在追？融資膨脹了嗎？
□ 否證條件：出現什麼訊號代表我錯了？（寫下來）
□ 停損計畫：錯了打算賠多少 %？在哪個訊號出場？
□ 部位大小：這筆佔總資金多少 %？
```

## 6.2 部位管理的三條鐵律

1. **單一持股不超過總資金的 15~20%**（新手建議更低）。分析可以錯，但不能一次錯到重傷。
2. **不用槓桿起步**：融資會把「暫時的錯」變成「被迫實現的錯」。等你有連續一年的正期望值紀錄再考慮。
3. **加碼只加在「對的部位」**：賺錢且論點更強時可加碼；虧損攤平是把資金持續投入一個已被市場投反對票的判斷——攤平前先重新走一次 6.1 檢查表，把它當一筆全新的交易審查。

## 6.3 停損：基於「否證」而非「金額」

兩種停損邏輯並用，先到先出：
- **論點停損**：進場理由被否證（月營收轉弱、漲價破局、法人反手連賣）→ 無論賠多少都出場。
- **保險停損**：技術位階破壞（跌破起漲點、跌破季線且無量反彈）或虧損達到你預設的上限（例如 -10%~-15%）→ 出場。這條是防止「論點停損」被自己的心理合理化拖延。

**心理提醒**：人腦天生損失趨避——賠錢時想凹、賺錢時想跑，剛好和正確做法相反。對抗它的唯一方法是**進場前就白紙黑字寫好規則，執行時不再重新思考**。

# 附錄 B｜新手十大常見錯誤（本手冊的反面教材）

1. 用第五層資訊（群組明牌）做決策
2. 在族群行情第 4 週、人人都在講的時候追進（正乖離不看）
3. 把循環股的低本益比當便宜
4. 營收大增就買，沒看毛利率方向
5. 沒寫否證條件，套牢後才開始找續抱的理由
6. 用「回本」當賣出標準，而非「論點是否成立」
7. 虧損攤平、獲利卻急著跑（賺賠比長期必輸）
8. 單一持股比重過高 + 使用融資
9. 把 AI 或任何分析（包括本手冊作者）的推論當事實，不自行核實原始資料
10. 沒有交易日誌，同一個錯誤犯三遍而不自知
