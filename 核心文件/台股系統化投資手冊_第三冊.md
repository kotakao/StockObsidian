# 台股系統化投資與量化研究手冊（三部曲・第三冊）
## ——從「會研究」到「有系統」：把判斷變成可驗證、可迭代的規則

> **本冊定位**：手冊一給你防守，手冊二給你研究深度，本冊解決最後一個問題——**人**。
> 再好的分析能力，若每次執行都取決於當天的情緒與記憶，長期績效就是隨機的。系統化的意思是：把判斷寫成規則、把規則交給流程、把流程的結果記錄下來迭代。本冊也會銜接你的 Python 資料專案，讓程式成為系統的地基。
> **前置條件**：完成手冊一、二；具備基礎 Python 能力（有資料抓取專案經驗即可）。

# 第 1 章｜為什麼需要系統：先認識你大腦的原廠缺陷

行為財務學已充分證明的偏誤，對照到交易行為：

| 偏誤 | 交易中的樣子 | 系統化解法 |
|---|---|---|
| 損失趨避 | 虧損凹單、獲利急跑 | 進場前寫死出場規則（手冊一 6.3） |
| 確認偏誤 | 持股後只看利多新聞 | Buy Case 強制寫空方論述（手冊二附錄） |
| 近因偏誤 | 用最近三天的盤感推翻三個月的研究 | 決策依據綁定「檢查表」而非盤感 |
| 稟賦效應 | 研究越深越捨不得賣 | 否證條件在買進前白紙黑字 |
| 過度自信 | 連勝後加大部位、上槓桿 | 部位規模由公式決定，不由信心決定 |
| 錨定效應 | 死守自己的成本價、前波高點 | 決策輸入中禁止出現「我的成本」 |

**系統的定義**：一組寫下來的規則，涵蓋「看什麼（資料）→ 何時進（訊號）→ 買多少（部位）→ 何時出（停損停利）→ 如何檢討（復盤）」，且每一環都留下紀錄。本冊五~七章就是依這條鏈展開。

# 第 2 章｜打造個人資料管線（銜接你的 Python 專案）

## 2.1 目標架構

```
[資料源] FinMind / TWSE / TPEx OpenAPI
    ↓ 每日排程抓取（含節流、重試、快取）
[儲存層] SQLite（單機夠用）：
    prices(日價量) / monthly_revenue(月營收) /
    financials(季財報) / chips(法人+融資+借券) / valuation(PE/PB/殖利率)
    ↓
[品質檢查層] 每次更新後自動執行（見 2.2）
    ↓
[計算層] 衍生指標：YoY、乖離率、法人連買天數、估值分位數…
    ↓
[輸出層] 每日晨報（你的觀察清單狀態）＋ 篩選結果
```

## 2.2 資料品質檢查（沒有這層，後面全是垃圾進垃圾出）

每次資料更新後自動檢查並記 log：
1. **完整性**：今日應有 N 檔股票資料，實際入庫幾檔？缺哪些？
2. **新鮮度**：最新日期是否為最近交易日？（防 API 靜默失敗）
3. **合理性**：漲跌幅超出 ±10% 的紀錄（台股漲跌幅限制）→ 標記人工檢查（可能是除權息未還原）
4. **除權息與還原價**：技術指標一律用還原股價計算，否則每年除息日都會產生假跳空訊號——這是台股量化最常見的資料坑
5. **缺失值統計**：每欄缺失比例，突然上升代表上游欄位變更

## 2.3 兩個台股特有的資料細節

- **月營收公布時間差**：10 日前公布上月營收，你的回測若假設「月初就知道當月營收」就是前視偏差（第 4 章詳述）。資料表要保留「公布日」欄位。
- **財報公布時間差**：Q1 財報 5/15 才公布。回測使用財報數據時，生效日必須設在公布日之後，不是季底。

# 第 3 章｜把研究規則翻譯成量化濾網

## 3.1 從手冊一、二的規則到可計算條件（範例對照）

| 原始規則（人話） | 量化條件（程式話） |
|---|---|
| 營收動能轉強 | 月營收 YoY > 0 且連續 3 個月遞增；或 YoY 由負轉正 |
| 不追高 | 收盤價對 20 日均線乖離 < +15% |
| 法人默默佈局 | 投信連續買超 ≥ 3 日，且 20 日累計買超 > 0 |
| 低基期 | 現價位於近 250 日高低區間下半部；或 PE 位於自身 5 年分位數 < 50% |
| 籌碼不擁擠 | 融資餘額 20 日增幅 < 20% |
| 盈餘品質 | 近 4 季 OCF/NI 平均 ≥ 0.8 |
| 循環股避開獲利頂 | 排除「PE < 8 且毛利率創 8 季新高」的循環股 |

## 3.2 因子思維入門（讓你的濾網有理論根基）

學術與實務上長期有效的因子家族，你的濾網其實都是它們的變形：
- **動能（Momentum）**：過去 3~12 個月強者恆強（但短期 1 個月常反轉）
- **品質（Quality）**：高 ROE、穩定毛利率、低負債、高盈餘品質
- **價值（Value）**：低 PB/PE 分位數（在台股對循環股要小心使用，見 3.1 最後一條）
- **規模與流動性**：小型股報酬高但波動與流動性風險大

重點不是背因子，而是：**你的每一條濾網，應該能說出它屬於哪個因子、為什麼長期應該有效**。說不出來的條件就是過擬合的溫床。

## 3.3 濾網的正確用途

量化濾網的產出是「**候選清單**」，不是「買進清單」。系統負責把 1,800 檔縮成 20 檔，手冊二的深度研究負責從 20 檔裡挑 3 檔並寫 Buy Case。人機分工：機器管廣度與紀律，人管深度與例外。

# 第 4 章｜回測方法論與統計陷阱（本冊最重要的一章）

回測的目的不是「找到會賺的策略」，而是「**殺死不會賺的策略**」。心態先對，方法才會對。

## 4.1 五大回測偏差（每一個都足以讓假策略看起來像聖杯）

1. **前視偏差（Look-ahead bias）**：用了當時還不知道的資料。台股三大高發區：月營收生效日（2.3）、財報生效日（2.3）、用「當日收盤價」執行「當日才產生的訊號」（實務上你只能用次日開盤價成交）。
2. **存活者偏差**：回測樣本只含「活到今天」的股票，下市的地雷股全被剔除 → 報酬高估、風險低估。資料庫必須保留下市股（FinMind 有 TaiwanStockDelisting 可用）。
3. **過度擬合（Overfitting）**：參數調到在歷史資料上完美 → 5 個以上可調參數的策略基本上是在擬合噪音。防禦：參數越少越好；做**參數敏感度測試**（把 20 日改成 15/25 日，績效若崩潰，代表 20 日是擬合出來的幸運數字）。
4. **多重檢定問題**：測 100 個策略，就算全是隨機的，也會有幾個「統計顯著」。你丟棄的每一個失敗版本，都在墊高倖存版本「純屬運氣」的機率。防禦：紀錄你總共測過幾版；用**樣本外資料**做最終審判（例：2016~2022 開發，2023~2026 只驗證一次、不回頭調參）。
5. **成本與流動性忽略**：台股來回成本約 0.4~0.6%（手續費+證交稅），加上滑價。高週轉策略扣完成本常由盈轉虧；小型股回測的大部位在實盤根本買不到那個價。回測必須內建成本模型與成交量上限。

## 4.2 一份回測報告的最低標準

- 年化報酬、**最大回撤（MDD）**、報酬/回撤比、勝率、賺賠比、交易次數（樣本數 < 30 筆的回測沒有統計意義）
- 分年度績效（是不是只靠某一年的大行情？）
- 與大盤（0050）同期對照——跑不贏買了就忘的 0050，策略就沒有存在價值
- 參數敏感度表
- 明確標註：資料期間、成本假設、成交價假設、樣本內/外切分

## 4.3 統計上的誠實

- 回測績效是「該規則在**那段歷史**的表現」——這是事實；「未來也會如此」——這是推論，且市場結構會變（regime change），本輪 AI 行情的規律不保證下一輪成立。
- 樣本量意識：多頭市場裡測出來的做多策略，只證明了「多頭時做多會賺」。至少要涵蓋一次完整的空頭（如 2022）才有資格談穩健性。

# 第 5 章｜部位管理的數學：決定「買多少」比「買什麼」更影響長期存活

## 5.1 期望值：交易系統的靈魂公式

```
期望值 EV = 勝率 × 平均獲利 − 敗率 × 平均虧損
```
- 勝率 40% 但賺賠比 3:1 → EV = 0.4×3 − 0.6×1 = +0.6（優秀系統）
- 勝率 70% 但賺賠比 1:3 → EV = 0.7×1 − 0.3×3 = −0.2（長期必死，但因為常常贏，體感很好——這就是凹單系統的數學面貌）
- 用你的交易日誌（手冊一 6.4）每季計算自己的實際 EV，這是最誠實的成績單。

## 5.2 風險固定法（建議新手到中階的預設方案）

```
每筆交易的部位張數 = (總資金 × 單筆風險上限%) ÷ (進場價 − 停損價)
```
- 單筆風險上限建議 0.5%~1%（意即停損被打到時，總資金只縮水 0.5~1%）
- 這個公式自動實現：停損越遠 → 部位越小；波動越大的股票 → 買越少。部位由風險決定，不由信心決定（呼應第 1 章）。

## 5.3 凱利公式：知道它，然後遠離全凱利

```
最適比例 f* = 勝率 − 敗率/賺賠比
```
- 理論最大化長期複利，但：參數估計誤差極大 + 全凱利的回撤深到沒有人性受得了。實務共識是用 **1/4 ~ 1/2 凱利**，或直接用 5.2 的風險固定法。
- 凱利的真正價值是負向使用：算出 f* ≤ 0 的交易（期望值為負）→ 正確部位是 0。

## 5.4 回撤的殘酷算術（背下來）

| 虧損 | 回本需要漲 |
|---|---|
| −10% | +11% |
| −20% | +25% |
| −33% | +50% |
| −50% | +100% |

資金曲線管理規則範例：當月虧損達總資金 −6% → 當月停止開新倉，只管理舊倉；連續觸發兩個月 → 全面降部位到一半，回頭檢查系統是否失效。**熔斷規則要在賺錢的時候寫好，虧錢的時候人是寫不出理性規則的。**

# 第 6 章｜投資組合層的思維

- **核心-衛星結構**：核心（例 50~70%）放指數 ETF 或高可信度長期持股；衛星（30~50%）執行你的波段系統。好處：系統失靈時你還在市場裡，不會被迫在最壞時點重新開始。
- **曝險上限**：單一持股 ≤ 15%；單一產業/題材 ≤ 30%——台股 AI 供應鏈的陷阱是「五檔不同名字、同一個曝險」（散熱+電源+載板全綁 AI capex），相關性高的持股要合併計算曝險。
- **現金水位是部位**：市況（例如指數跌破季線、你的系統勝率驟降）觸發時提高現金，是系統的一部分而非「看不懂就空手」的情緒行為。
- **再平衡**：每季把偏離目標配置超過 ±5 個百分點的部位調回——機械性地實現「漲多減碼、跌深補回核心」。

# 第 7 章｜決策品質與復盤系統

## 7.1 決策與結果分離（撲克選手的核心素養）

| | 好結果 | 壞結果 |
|---|---|---|
| **好決策** | 實至名歸 | 運氣不好（不需自責，繼續執行） |
| **壞決策** | **僥倖（最危險的象限，會強化壞習慣）** | 罪有應得（最有學習價值） |

復盤時每筆交易先問「依當時可得的資訊，決策對嗎」，再看賺賠。賺錢的壞決策必須被記錄為壞決策。

## 7.2 三層復盤節奏

- **每筆**：交易日誌（手冊一 6.4 模板）＋標注四象限
- **每月**：統計執行率（實際依規則執行的比例——這是比報酬率更領先的健康指標）、EV、最大單筆虧損是否超出風險預算
- **每季**：系統層檢討——濾網命中率、否證條件的準確度、是否出現 regime change 跡象；手冊二的 Buy Case 逐份重讀批改

## 7.3 Tilt（情緒失控）偵測清單

出現以下任一行為 → 強制休息至少三個交易日：
- 當天做了超過計畫數量的交易／沒寫日誌就下單
- 為了「把今天虧的賺回來」而開倉
- 部位大小偏離公式（憑感覺加倍）
- 頻繁盯盤到影響本業與睡眠

# 第 8 章｜把三冊整合成你的投資作業系統（OS）

```
【每日 15 分鐘】（自動化後）
  資料管線晨報：觀察清單訊號、持股否證條件檢查、法人動向
【每週 60 分鐘】
  輪動週記（手冊一 5.3）＋濾網跑一次產出候選清單
【每月】
  月營收季：更新追蹤表 → 深度研究候選（手冊二）→ 執行率與 EV 統計
【每季】
  財報+法說季：盈餘品質檢查、管理層可信度更新、
  Buy Case 批改、系統層復盤、組合再平衡
【每年】
  樣本外驗證、規則版本迭代（改動要有書面理由與生效日）、年度總結
```

**三冊的能力驗收標準**：
- 冊一（防守）：連續 6 個月無「無計畫交易」、單筆虧損從未超過風險預算
- 冊二（深度）：Buy Case 一個月後回看站得住的比例 > 60%；能在新聞前從數據預判變化
- 冊三（系統）：實際 EV 為正且執行率 > 90%；經歷一次 10% 級別的大盤修正而系統照常運作

# 附錄 B｜回測上線前檢查清單（影印貼在螢幕旁）

```
□ 訊號使用的每個欄位，在訊號日當天真的已經公布了嗎？（前視）
□ 樣本含下市股嗎？（存活者）
□ 可調參數 ≤ 3 個？做過敏感度測試？（過擬合）
□ 這是我測的第幾版？樣本外驗證過了嗎？（多重檢定）
□ 扣過成本與滑價？考慮過成交量限制？（成本）
□ 交易次數 ≥ 30？涵蓋至少一次空頭？（樣本量）
□ 跑贏同期 0050 嗎？（機會成本）
□ MDD 我真的承受得住嗎？（把 MDD 換算成金額感受一次）
```

*三部曲至此完成。防守（一）、深度（二）、系統（三）——最後提醒：系統的目的不是消滅判斷，而是讓你的判斷只花在值得判斷的地方，並讓每一次判斷都留下可以學習的紀錄。祝長期存活，複利自來。*
