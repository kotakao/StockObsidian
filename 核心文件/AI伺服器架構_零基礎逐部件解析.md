# AI 伺服器硬體架構:從一顆晶片到一座機櫃

> 索引:[[族群輪動索引_AI供應鏈]]。本文為**硬體架構教學**(以常青原理為主,標「當前世代」者會隨產品演進更新),**非投資建議**。各部件的即時營收/籌碼見對應族群筆記。
> 讀法:先看「Part 0 三個心智模型」建立直覺 → 再看「Part 1 部件順序總表」掌握全貌 → 最後「Part 2」逐一深入。

## Part 0｜先建立三個心智模型(看懂後面都輕鬆)

### 模型一:一台 AI 伺服器到底在做什麼?
說穿了只有一件事:**把「矩陣乘法」做到極致地快**。AI 模型(不管訓練或推論)底層幾乎都是天文數字量的「乘加運算」(乘一下、加一下,英文叫 MAC)。所以整台機器的存在,都是為了**餵飽一顆(或一堆)專門做乘加的大晶片,讓它不要停下來**。

### 模型二:整台機器只做五件事(加兩件配套)
| # | 這件事 | 白話 | 誰負責 |
|---|---|---|---|
| 1 | **算** | 做乘加運算 | GPU / ASIC 晶片 |
| 2 | **記** | 把資料放在晶片旁邊隨時取用 | HBM 記憶體 |
| 3 | **餵/傳** | 把資料在晶片↔晶片↔機櫃之間搬來搬去 | 連接器、銅纜、光通訊、交換器 |
| 4 | **供電** | 把插座的電,精準地變成晶片能用的電 | 電源、功率元件、被動元件 |
| 5 | **散熱** | 把晶片產生的熱帶走(不然燒毀) | 氣冷 / 液冷 |
| +6 | **承載** | 把上面全部零件裝在一起、連通 | 載板、PCB、機構件 |
| +7 | **把關** | 每個環節都要驗好壞 | 測試與檢測 |

**只要記住「算、記、傳、供電、散熱」五個字,你就掌握了 AI 伺服器的骨架。**

### 模型三:「瓶頸會移動」——這就是族群輪動的物理根源
運算需求暴增時,不會所有環節同時卡住,而是**一個環節先塞住(瓶頸),解決後換下一個塞住**。順序大致是:
> 算力(晶片)→ 記憶體頻寬(HBM)→ 封裝產能(CoWoS)→ 載板/材料 → 供電 → 散熱 → 傳輸(銅轉光)。

**錢(資金)會跟著「當下最卡的那個環節」跑**——這就是 [[族群輪動索引_AI供應鏈]] 在追的東西。看完這份文件,你會從「物理原理」理解為什麼是這個順序。

## Part 2｜逐部件深入解析

> 每個部件用四段講:**【它是什麼】【負責什麼工作】【目前技術怎麼做】【一句白話】**。

### ① GPU / ASIC 運算晶片
- **它是什麼**:一顆專門做大量平行運算的大晶片。兩條路線:**GPU**(NVIDIA、AMD 出的通用加速器)vs **ASIC**(客戶自己設計的專用晶片,如 Google TPU、AWS Trainium,由世芯/創意/博通等協助設計)。
- **負責什麼工作**:整台機器的「算」。衡量它強不強看三個數字——**算力**(每秒幾次運算)、**記憶體頻寬**(餵料多快)、**互連頻寬**(和別顆晶片溝通多快)。AI 越大,後兩者常比算力更關鍵。
- **目前技術怎麼做**:用台積電**最先進製程**(如 N3/N2 級)+ **EUV 極紫外光微影**把電晶體做到極小。但遇到**物理天花板**:單顆晶片面積受「光罩極限」(約 858 平方毫米)限制,做不大;功耗也已飆到單顆 700~1400W。**解法是不再追求單顆做大,而是把多顆小晶片(chiplet)用先進封裝拼起來**——這就引出 ③。
- **一句白話**:它是超大工廠的生產線,但廠房大小有物理上限,所以只能蓋很多棟連在一起。
- 連結:[[族群_晶圓代工與先進封裝]]、[[族群_ASIC設計服務]]

### ② HBM 高頻寬記憶體
- **它是什麼**:High Bandwidth Memory,把多層 DRAM 晶片**垂直疊起來**,緊貼在 GPU 旁邊。
- **負責什麼工作**:「記」與「餵」。AI 最常見的瓶頸其實不是「算不夠快」,而是「**料餵不上**」(業界叫**記憶體牆**)。HBM 用**超寬的資料通道**(單顆 1024-bit 以上,等於幾千條線並排)一次搬海量資料,餵飽 GPU。
- **目前技術怎麼做**:世代從 **HBM3E → HBM4**(2026 年導入,NVIDIA 新平台 Rubin 指定要用 HBM4)。技術重點:**TSV 矽穿孔**(在晶片打洞讓上下層直接通電)、堆疊 8/12/16 層越疊越高、**base die 邏輯化**(最底層放客製邏輯)。難點是**良率**與**散熱**(疊那麼高,中間的熱出不來)。三大供應商:SK 海力士、三星、美光。
- **一句白話**:GPU 旁邊的貼身超大倉庫,配一條超寬輸送帶——不是走一條小路搬料,而是幾千條並排一起搬。
- 連結:[[族群_利基記憶體]](此族群同時涵蓋利基與主流 DRAM/HBM 支;HBM 是 AI 主線)

### ③ 先進封裝(CoWoS / SoIC)
- **它是什麼**:把「運算晶片 + 好幾顆 HBM」在一個小基板上**精密拼裝/堆疊成一顆大晶片**的技術。
- **負責什麼工作**:解決 ① 的面積與 ② 的距離問題。GPU 和 HBM 要**靠超近**、用**上萬條超短線**連起來,頻寬才夠、功耗才低——這靠先進封裝實現。
- **目前技術怎麼做**:
  - **CoWoS**(Chip on Wafer on Substrate):把晶片放在一片「矽中介層(interposer)」上再接到基板;變體 CoWoS-S/R/**L**(L 用矽橋+重佈線,做最大面積,當前旗艦 GPU 用它)。
  - **SoIC**(3D 堆疊):晶片直接**面對面疊**,用**混合鍵合(hybrid bonding)** 讓上下層以奈米級間距對接,比打線密上百倍。
  - **瓶頸**:CoWoS 產能是這兩年最有名的卡點——台積電擴產仍供不應求,NVIDIA 就吃掉一大半。
- **一句白話**:把好幾棟廠房用最短的空橋連成一體,讓工人(資料)不用繞遠路。
- 連結:[[族群_晶圓代工與先進封裝]]、瓶頸外溢見 [[連接_先進封裝瓶頸外溢]]

### ④ ABF 載板(IC 基板)
- **它是什麼**:封裝好的晶片,底下那塊佈滿超細線路的「小板子」,英文 IC substrate,高階用 **ABF 材料**(味之素的一種絕緣膜)。
- **負責什麼工作**:當**晶片與主機板之間的翻譯/轉接層**。晶片的接腳極細極密(微米級),主機板(PCB)做不到那麼細;載板負責**把密腳位「攤開」成 PCB 接得上的間距**,同時傳電、傳訊號。
- **目前技術怎麼做**:層數越疊越多、線寬越做越細、面積越做越大(AI 晶片載板面積是手機晶片的數十倍)。難點:大面積下的**翹曲、良率、對位**。高階 ABF 載板長年被少數日/台/韓廠掌握(欣興、南電、景碩、Ibiden、Unimicron 等)。
- **一句白話**:晶片的腳太細太密,主機板接不住,載板就是中間那塊「變密為疏」的精密轉接插座。
- 連結:[[族群_ABF載板]]、材料外溢見 [[連接_ASIC需求外溢載板]]

### ⑤ PCB / CCL 主機板
- **它是什麼**:印刷電路板(PCB)是承載所有零件的大板子;**CCL(銅箔基板)** 是做 PCB 的基礎材料(銅箔+玻纖布+樹脂壓合成的板材)。
- **負責什麼工作**:「承載」與「連通」。所有晶片、電源、連接器都焊在上面,靠板內的銅線互相連通。AI 伺服器訊號極快,對板材的**電氣特性(低損耗)** 要求極高。
- **目前技術怎麼做**:**高層數**(20~30 層以上)、**低損耗高頻材料**(Low-Df CCL)、更平整的**玻纖布**與**低粗糙度銅箔**(訊號越快,材料稍有雜訊就衰減)。所以 AI 讓「板材上游(玻纖布、銅箔、樹脂)」跟著受惠。
- **一句白話**:整台機器的道路與地基;車(資料)跑得越快,路面就要鋪得越平越好。
- 連結:[[族群_PCB與CCL]]

### ⑥ 被動元件(MLCC、電感等)
- **它是什麼**:不「主動」放大或運算、但不可或缺的小零件。最大宗是 **MLCC(積層陶瓷電容)**,一台 AI 伺服器用量以萬顆計。
- **負責什麼工作**:三件事——**穩壓**(電壓別忽高忽低)、**濾雜訊**(把電源的毛刺濾掉)、**瞬間供電**(晶片運算負載瞬間暴增時,旁邊的電容先頂上,像小電池)。AI 晶片電流變化又大又快,被動元件的數量與等級跟著升級。
- **目前技術怎麼做**:往**更小體積、更高電容值、更耐高溫/高電流**發展;貼近晶片的高階 MLCC 供不應求(村田、國巨、華新科等)。
- **一句白話**:水塔(穩水壓)+ 濾網(去雜質)+ 小電池(突然要用水時先頂著),三合一。
- 連結:[[族群_被動元件]]

### ⑦ 功率元件 / VRM(電壓調節模組)
- **它是什麼**:把板上的電(48V 或 12V)**降壓**成 GPU 核心真正能用的極低電壓(約 0.6~0.9V)的一組零件,核心是 **MOSFET(功率電晶體)** + 控制 IC,合稱 **VRM**。
- **負責什麼工作**:「供電」的最後、也是最關鍵一段。AI 晶片吃**極大電流**(單顆可達上千安培),而且要求電壓**穩到毫伏級**、反應**快到奈秒級**。VRM 要在晶片旁邊,把大電流又穩又快地灌進去。
- **目前技術怎麼做**:
  - **多相供電**(把大電流拆成很多相並聯,分攤發熱)。
  - **48V 直入**:資料中心走 48V 進機櫃比 12V 省銅、省損耗,是當前趨勢。
  - **垂直供電(Vertical Power Delivery)**:把 VRM 從晶片旁邊移到晶片**正下方/背面**,縮短路徑、降低壓降——這是最新方向。
  - 材料上,**GaN(氮化鎵)、SiC(碳化矽)** 等第三代半導體讓功率轉換更高效。
- **一句白話**:自來水從高壓幹管一路減壓,VRM 是最後貼在你家水龍頭前的那顆「精密穩壓閥」,還要能瞬間開超大水量又不噴。
- 連結:[[族群_功率元件]]

### ⑧ 電源 PSU / BBU(供電與備援)
- **它是什麼**:**PSU**(電源供應器)把資料中心的交流電變成伺服器用的直流電;**Power Shelf** 是機櫃級的集中供電;**BBU(電池備援單元)/ 超級電容** 在市電波動或瞬斷時頂住。
- **負責什麼工作**:「供電」的最上游。機櫃功率動輒上百 kW,對「電從哪來、斷電怎麼辦、尖峰怎麼削」要求極高。**BBU 讓機櫃在市電微中斷時不當機、並在瞬間尖峰時放電削峰**。
- **目前技術怎麼做**:走向**高壓直流(HVDC,如 400V/800VDC)** 以降低傳輸損耗;BBU/超級電容被超大型資料中心大量預訂(供電本身已成實體瓶頸——變壓器、開關設備交期以「年」計)。
- **一句白話**:整棟樓的總水閘(PSU)+ 停水時的備用水塔(BBU);樓越高、用水越兇,這兩個越關鍵。
- 連結:[[族群_電源二階與BBU]]

### ⑨ 高速連接器 / Socket
- **它是什麼**:讓晶片、板卡、模組之間**可插拔又能高速傳訊**的金屬接點。GPU 底下的 **socket(插座)**、板對板連接器都屬此類。
- **負責什麼工作**:「傳」的實體介面。訊號速率越高(見 ⑩),連接器的**阻抗控制、訊號完整性**要求越苛刻——差一點點,高速訊號就失真。
- **目前技術怎麼做**:往**更高頻(對應 224G)、更密腳位、更好散熱**演進;GPU 換代(如 Rubin 平台)常帶來新 socket 規格,直接拉動連接器單機用量與單價(嘉澤等)。
- **一句白話**:高速公路的交流道——車速越快,交流道的設計就要越精密,否則一上一下就打滑。
- 連結:[[族群_連接器與線材]](嘉澤 3533、宏致 3605、貿聯-KY 3665)

### ⑩ 高速銅纜(DAC / ACC)
- **它是什麼**:短距離傳高速訊號用的**銅線纜**。DAC(直接連接銅纜)、ACC(主動式銅纜)。
- **負責什麼工作**:機櫃「內部」或「近距離」的高速連線。銅在短距離**又便宜又省電**,所以機櫃內優先用銅(例如 NVL72 機櫃內部大量用銅背板連接 GPU)。
- **目前技術怎麼做**:單通道速率從 112G 走向 **224G(PAM4 調變)**;距離拉長或速率再上去,銅會衰減太多 → 才換成光(⑪)。「銅能撐多遠」決定了「光從哪裡開始接手」。
- **一句白話**:近距離用便宜耐用的專用管線就好,沒必要每一段都用貴的。
- 連結:[[族群_連接器與線材]](貿聯-KY 3665 高速線材)

### ⑪ 光通訊 / CPO / 矽光子
- **它是什麼**:用**光**而非電來傳資料。**光模組**把電訊號轉成光、送過光纖、再轉回電;**CPO(共同封裝光學)** 是把「光引擎」直接搬到交換晶片/GPU 旁邊封在一起。
- **負責什麼工作**:「傳」的長距離段。距離一長或速率一高,銅纜就會衰減、耗電暴增;光傳得**又遠又快又相對省電**。AI 叢集動輒幾萬顆 GPU 互連,光通訊是關鍵。
- **目前技術怎麼做**:
  - 速率:400G → 800G → **1.6T**。
  - **銅轉光的臨界點正在往晶片端靠近**:傳統可插拔光模組 → **LPO(線性直驅)** → **CPO(光引擎與晶片共封)**,一步步縮短電走的距離、省電。
  - **矽光子**:用半導體製程做光學元件(調變器、波導),台積電 COUPE、Broadcom/NVIDIA 的 CPO 交換器是代表。
  - **時程**:CPO 交換器 2026 年**初期出貨**、**廣泛放量多落在 2027 年以後**(良率、光引擎、封裝產能是卡點)——所以短期「話題常跑在營收前面」。
- **一句白話**:與其把信送到很遠的中央郵局再轉運(電走長路很耗電),不如把郵局直接搬到你家門口(光引擎搬到晶片旁),少走冤枉路。
- 連結:[[族群_光通訊與CPO]]

### ⑫ 網路交換 / NIC / DPU
- **它是什麼**:**交換器(Switch)** 決定資料在成千上萬顆晶片間怎麼走;**NIC(網卡)** 是每台伺服器的網路出入口;**DPU** 幫 CPU 分擔網路/資安等雜務。
- **負責什麼工作**:「傳」的大腦。單顆 GPU 再強,幾萬顆要協同訓練一個大模型,**它們之間的網路**若塞住,全部一起等——所以互連網路(scale-up / scale-out)是 AI 叢集的命脈。
- **目前技術怎麼做**:交換晶片頻寬往 **51.2T → 102.4T** 走;架構分「機櫃內高速互連(scale-up,如 NVLink)」與「跨機櫃網路(scale-out,如 Ethernet/InfiniBand)」;CPO 也最先用在交換器上。
- **一句白話**:全城的交通號誌與路由中心——路口設計不好,再多好車也塞死。
- 連結:[[族群_AI伺服器與ODM]](系統/網路層)

### ⑬ 散熱(氣冷 → 液冷)
- **它是什麼**:把晶片產生的熱帶走的整套系統。從傳統**氣冷(風扇+散熱鰭片)** 走向 **液冷**。
- **負責什麼工作**:「散熱」。晶片過熱會**自動降速(降頻)甚至燒毀**,所以散熱直接決定晶片能不能全速跑。AI 機櫃功率密度暴增(單櫃已達 120~130kW,新一代上看 300kW 級以上),**氣冷已經帶不走那麼多熱**。
- **目前技術怎麼做**:
  - **冷板式(D2C 直接接觸晶片)**:銅水冷板貼在晶片上,冷卻液流過帶走熱——當前 AI 機櫃主流。
  - **CDU(冷卻液分配單元)**:機櫃級的「心臟+腎臟」,推動並調節冷卻液循環。
  - **快接頭(UQD)/ manifold**:讓液冷管路能快速接拔、分流不漏液——AI 液冷含量大增的零件。
  - **浸沒式(immersion)**:整台泡在絕緣冷卻液裡,更極端但導入較慢。
  - 液冷滲透率快速上升(業界估 2026 年多數新 AI 機櫃導入液冷)。
- **一句白話**:晶片是個一直發高燒的超人,風扇擦汗已經不夠,得直接用水管貼著幫它降溫。
- 連結:[[族群_散熱二階]](冷板/CDU/快接頭等二階零組件)

### ⑭ 機構件(機殼、滑軌、結構件)
- **它是什麼**:機殼、滑軌、支撐架、扣具等「不通電但撐住一切」的金屬/結構零件。
- **負責什麼工作**:「承載」的實體。固定沉重的液冷板卡、承受重量與震動、**讓維修人員能像抽抽屜一樣抽換伺服器**(滑軌)。機櫃越重、越密、越貴,機構件的精度與強度要求越高。
- **目前技術怎麼做**:更高強度、更輕量、更精密的沖壓/CNC;液冷化後對**防漏、承重、公差**要求提升。
- **一句白話**:房子的樑柱與抽屜軌道——不起眼,但沒有它整棟垮、也沒法維修。
- 連結:[[族群_機構件]](川湖 2059 滑軌、勤誠 8210/營邦 3693 機殼)

### ⑮ 系統組裝(伺服器 → 機櫃)
- **它是什麼**:把上述所有零件組成一台伺服器、再把數十台整合成一整座「AI 機櫃」的環節,由 **ODM 代工廠**(鴻海、廣達、緯創/緯穎等)執行。
- **負責什麼工作**:「把東西真的裝出來、測好、出貨」。當代 AI 已經不是「賣一台伺服器」,而是**整櫃交付**(例如 NVIDIA NVL72 = 一櫃 72 顆 GPU + 36 顆 CPU 用高速背板連成「一台超大電腦」)。
- **目前技術怎麼做**:整櫃設計(rack-scale)、液冷整合、供電整合、系統級測試;誰能把「整櫃良率」與「交期」做好,誰就拿到大單。
- **一句白話**:把所有建材(零件)真的蓋成一棟能住人的大樓,還要通過驗收。
- 連結:[[族群_AI伺服器與ODM]]

### ⑯ 測試與檢測(貫穿全程)
- **它是什麼**:從晶圓、晶片、封裝、板卡到整機,每一關「驗好壞、挑不良」的環節。
- **負責什麼工作**:「把關」。任一環節壞一顆,整台幾百萬的機器就報廢,所以**測試強度隨複雜度暴增**。HBM 多層堆疊、chiplet 拼裝前都要先確認「每顆小晶片都是好的(KGD,已知良裸晶)」,否則拼上去才發現壞的,損失巨大。
- **目前技術怎麼做**:
  - **探針卡(probe card)**:晶圓階段一根根探針點測。
  - **測試座(test socket)**:封裝後成品測試的介面。
  - **系統級測試(SLT)、燒機(burn-in)**:模擬真實運作挑出早夭品。
  - 先進封裝把「**封裝前的 KGD 測試**」變成新剛需。
- **一句白話**:全程品管與健檢——越貴越複雜的病人,越要每一關都仔細檢查,不能等蓋好才發現地基有問題。
- 連結:[[族群_半導體測試與介面]]

## Part 3｜把它串起來:三條「流」貫穿全機

理解了零件,再看它們如何協同——整台機器同時跑三條流:

- **資料流(藍線)**:HBM ⇄ GPU(靠先進封裝的超短線)→ GPU ⇄ GPU(機櫃內銅纜/NVLink)→ 機櫃 ⇄ 機櫃(光通訊/交換器)。**瓶頸在哪,算力就被誰拖住。**
- **電流(紅線)**:市電 → PSU → Power Shelf(48V/HVDC)→ VRM 降壓 → 被動元件穩壓 → 灌進 GPU。**每一級都在損耗與發熱,越接近晶片要求越變態。**
- **熱流(橘線)**:GPU/HBM 發熱 → 冷板吸熱 → 快接頭/manifold 導流 → CDU 交換 → 帶出機櫃。**電流有多大,熱流就有多大,散熱必須同步升級。**

> 三條流是**互相牽制**的:想算更快 → 要餵更多料(資料流)→ 要灌更多電(電流)→ 就產更多熱(熱流)。**任何一條先到極限,就是下一個瓶頸、下一棒族群。**

| 部件 | 用量(量級) | 說明 |

| GPU | 一櫃 **72 顆**(NVL72)【事實】 | 18 個 compute tray,每 tray 4 顆 Blackwell |

## Part 7｜延伸專章二:scale-up vs scale-out(兩層網路,別搞混)

AI 叢集的網路分**兩層**,瓶頸與受惠零件不同:

| | **Scale-up(縱向擴展)** | **Scale-out(橫向擴展)** |
|---|---|---|
| 白話 | 把「一櫃內多顆 GPU」黏成**一台超大 GPU** | 把「幾千台伺服器」連成**一座資料中心** |
| 技術 | NVLink / NVSwitch(NVIDIA)、私有高速互連 | InfiniBand / Ethernet(乙太網) |
| 距離 | 機櫃內(公分~公尺) | 跨櫃、跨機房(公尺~百公尺) |
| 媒介 | **銅為主**(短距省電,如 NVL72 銅背板) | **光為主**(長距,光模組/CPO) |
| 要求 | 頻寬極高、延遲極低(GPU 要像共用記憶體) | 可擴到數萬節點、成本/功耗可控 |
| 受惠零件 | 高速銅纜、連接器、NVSwitch | 光通訊/CPO、交換器、NIC |

- **為什麼要分兩層**:GPU 之間若都用光,成本/功耗爆炸;若都用銅,拉不遠。於是「近的用銅(scale-up)、遠的用光(scale-out)」。
- **CPO 先落地在哪**:先用在 **scale-out 的交換器**(埠數多、距離長,最需要省電),再逐步往 GPU 端靠近。
- **銅的臨界點**:單通道速率往 224G 走,銅能撐的距離縮短 → **「銅退光進」的分界線往機櫃內部推進**,是光通訊放量的長期驅動。
- 連結:[[族群_光通訊與CPO]]、[[族群_AI伺服器與ODM]]

## Part 8｜延伸專章三:先進封裝的下一代(解 CoWoS 瓶頸的方向)

CoWoS 產能是當前最有名的卡點,業界往三個方向解:

1. **混合鍵合(Hybrid Bonding)**
   - 現在晶片疊晶片多用「微凸塊(micro-bump)」連接;混合鍵合是**銅對銅直接鍵合、沒有凸塊**,間距從數十微米縮到 **1 微米以下**,連接密度上百倍。
   - 用途:SoIC 3D 堆疊、未來 HBM 更高層堆疊。難點:對位精度、潔淨度要求極高。

2. **玻璃基板(Glass Substrate)**
   - 用**玻璃**取代/補充 ABF 有機載板:更平整(利於大面積、細線路)、電氣特性更好、翹曲更小。
   - 時程:業界多指向 **2027 年以後**逐步導入;是載板的下一代主線之一。

3. **面板級封裝(Panel-Level Packaging, FOPLP)**
   - 從「圓形晶圓」改用「方形大面板」做封裝載體,**單次產出更多、面積利用率更高** → 提升先進封裝產能、降成本。

> 一句話:CoWoS 卡在「產能+面積+成本」,混合鍵合解「密度」、玻璃基板解「大面積與電氣」、面板級解「產能與成本」。這些是 [[族群_晶圓代工與先進封裝]]、[[族群_ABF載板]] 的中長期題材。
