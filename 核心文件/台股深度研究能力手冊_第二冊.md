# 台股深度研究能力手冊（三部曲・第二冊）
## ——從「會看數字」到「看懂公司與產業」

> **本冊定位**：手冊一教你防守（取得資料、看懂指標、不犯大錯），本冊教你建立**優勢**。
> 散戶在市場上的優勢只可能來自三件事：**看得更深**（理解比別人深）、**看得更早**（訊號比別人早）、**拿得更久**（別人拿不住的你拿得住）。本冊的每一章都在建造這三種能力之一。
> **前置條件**：已熟悉手冊一的資料來源、基本公式與風控紀律。

# 第 1 章｜財報三表連動與盈餘品質：學會抓出「數字很漂亮但有問題」的公司

## 1.1 三張報表在說什麼、如何互相牽制

- **損益表**：這段期間「帳面上」賺了多少 → 最容易被美化
- **資產負債表**：此刻公司「擁有什麼、欠什麼」→ 美化的痕跡會堆積在這裡
- **現金流量表**：實際的錢進出 → 最難造假，因為現金要嘛在要嘛不在

核心觀念：**淨利是「意見」，現金是「事實」**。損益表用應計基礎（賣出去就認列，錢沒收到也算），所以獲利可以靠會計判斷調節；現金流量表是實收實付。深度研究的第一步，就是用現金流去「審計」損益表。

## 1.2 盈餘品質三檢查（每季財報出來後的例行公事）

**檢查一：營業現金流 ÷ 稅後淨利（OCF/NI）**
- 長期（近 4~8 季平均）應該 ≥ 0.8。持續遠低於 1，代表帳面獲利沒有變成現金。
- 資料位置：Goodinfo 個股頁「現金流量表」，或財報狗現金流分析。
- 注意：單季可以因收款週期波動，看趨勢不看單點。

**檢查二：應收帳款與存貨增速 vs 營收增速**
- 應收帳款年增率 遠大於 營收年增率 → 可能在放寬收款條件塞貨衝營收。
- 存貨年增率 遠大於 營收年增率 → 賣不動（但漲價循環中的策略性備料是例外，需搭配產業情境判讀，這正是產業知識的價值）。

**檢查三：業外損益佔稅前淨利比重**
- 本業（營業利益）才反映競爭力。EPS 大增但主要來自處分資產、匯兌、投資收益 → 不可延續，估值不應給成長股倍數。
- 位置：損益表「營業外收入及支出」。

## 1.3 常見美化手法警訊清單

| 警訊 | 可能在做什麼 |
|---|---|
| Q4 單季毛利率異常跳動 | 年底存貨評價、費用集中調整 |
| 營收成長但毛利率長期下滑 | 降價搶單、產品組合惡化 |
| 頻繁的「一次性」費用（每年都有一次性） | 把經常性成本包裝成一次性 |
| 大量關係人交易 | 營收品質存疑 |
| 應收帳款週轉天數逐季拉長 | 塞貨、客戶付款能力惡化 |
| 現金很多同時借款也很多 | 現金可能有名無實（質押、受限） |

這份清單的用法不是「中一條就出局」，而是**中越多條、你要求的安全邊際就要越大**。

# 第 2 章｜估值方法論：從「本益比幾倍」到「現價隱含了什麼假設」

## 2.1 估值的本質與第一原則

估值 = 對公司未來現金流的定價。所有估值倍數（PE、PB、EV/EBITDA）都只是 DCF 的簡化速記。三個第一原則：

1. **估值是「區間」不是「數字」**——任何說得出小數點的目標價都是假精確。
2. **成長率、確定性、資本報酬率決定倍數高低**——高 PE 不等於貴，低 PE 不等於便宜。
3. **估值只在極端時有用**——在區間中段，估值對短期股價幾乎沒有解釋力；在極端高低檔，它是最好的風險溫度計。

## 2.2 工具箱：什麼股票用什麼尺

| 工具 | 適用 | 不適用 | 操作方式 |
|---|---|---|---|
| PE band（本益比河流圖） | 獲利穩定的成長股 | 虧損、景氣循環股 | 取近 5 年 PE 高低區間分五檔，看現價落在第幾檔（Goodinfo「本益比河流圖」有現成的） |
| PEG = PE ÷ 盈餘成長率 | 高成長股比較 | 成長率不可持續時失真 | PEG 明顯 >2 要求證成長的可持續性；<1 檢查是否有你沒看到的風險 |
| PB band + 產業報價 | 景氣循環股（記憶體、面板、航運、鋼鐵） | 輕資產公司 | 循環股在「PB 低 + 報價落底 + 全行業虧損」時反而接近買點；「PE 低 + 獲利創高」時接近賣點——與直覺相反，務必內化 |
| EV/EBITDA | 高折舊資本密集業、跨公司比較 | 金融業 | EV =市值＋淨負債；排除折舊政策差異 |
| 殖利率法 | 成熟穩定配息股 | 成長股 | 用歷史殖利率區間定位，並確認股利有現金流支撐 |

## 2.3 反向思考：隱含預期法（本章最重要的技巧）

與其問「這家公司值多少」，不如問「**現在的股價，隱含市場相信什麼？**」

操作步驟（不需要複雜模型）：
1. 現價 ÷ 合理倍數區間 → 反推市場定價的 EPS 是多少
2. 那個 EPS 需要營收成長多少 ％、毛利率到多少 ％ 才做得到？
3. 把這組隱含假設跟公司歷史紀錄、產能上限、產業天花板對照——**做得到嗎？**

範例思路：某股股價對應「明年 EPS 需要年增 80%、毛利率創歷史新高」才算合理 → 你買它，賭的就是這組假設全部成真。把賭注寫清楚，是深度研究者與追題材者的分水嶺。

## 2.4 估值的三個常犯錯誤

1. 用單一年度 EPS 給循環股估值（見 2.2 表）。
2. 拿不同商業模式的公司比 PE（代工 10 倍 vs IC 設計 25 倍是常態，不是誰便宜）。
3. 忽略股本變化：現增、CB 轉換會稀釋 EPS——查「股本形成」與流通在外 CB（公開資訊觀測站）。

# 第 3 章｜產業研究框架：判斷「這個生意好不好、現在在循環哪裡」

## 3.1 供需—庫存—報價三循環（電子業適用的核心模型）

任何硬體產業的中期波動都由這個循環驅動：

```
需求上升 → 供不應求 → 報價上漲 → 廠商擴產+客戶重複下單（overbooking）
→ 產能開出+需求放緩 → 供過於求 → 砍單+去庫存 → 報價下跌
→ 產能退出/資本支出縮減 → 供給收縮 → 回到起點
```

**你要追蹤的三個變數與資料源**：
- 報價：TrendForce 新聞（記憶體/面板）、產業媒體漲價報導、公司法說
- 庫存：財報存貨天數（全產業一起看，不只看單一公司）、下游客戶的庫存水位
- 資本支出：龍頭廠法說會 capex 指引——**本輪的擴產就是下輪的供過於求**，capex 大增後 12~24 個月要開始警惕

## 3.2 利潤池分析：整條供應鏈，誰賺走最多錢？

把一條供應鏈（如 AI 伺服器）從上游到下游列出，標注每一環的**毛利率與營益率**：

- 毛利率 50%+ 的環節：通常有技術/專利/認證門檻（如 IC 設計、關鍵材料）
- 毛利率 10~20%：組裝與規模生意（ODM）——賺管理財，量大但賠率有限
- **關注「毛利率正在結構性上升」的環節**：代表定價權正在移轉到它手上（例：規格升級使某零組件從標準品變客製品）

這個分析每半年更新一次，它會直接告訴你：同一個題材裡，該研究哪一層的公司。

## 3.3 定價權與成本曲線

問三個問題判斷一家公司在產業裡的位置：
1. 它漲價，客戶會走嗎？（轉換成本）
2. 產業景氣最差時，誰先虧損？（成本曲線位置——最後虧損的人擁有循環底部的生存權）
3. 客戶集中度多高？（單一客戶 >30% 是雙面刃：綁深但議價弱）

## 3.4 一頁產業報告模板（每研究一個新產業就寫一份）

```
產業名稱／日期：
1. 這個產業賣什麼、賣給誰？（兩句話）
2. 需求驅動力：現在成長靠什麼？可持續多久？【事實/推論分開】
3. 供給狀態：產能利用率？擴產計畫？進入門檻？
4. 循環位置：報價方向？庫存水位？（附資料來源與日期）
5. 利潤池：哪一環毛利率最高/正在上升？
6. 台股相關公司分層：真受惠（營收占比>20%）/ 部分受惠 / 純題材
7. 這個產業的「否證訊號」：什麼數據出現代表循環轉向？
```

# 第 4 章｜法說會解讀：建立「管理層可信度資料庫」

## 4.1 法說會 SOP

**會前**：讀上一次法說簡報，把管理層當時給的指引（營收展望、毛利率區間、產能時程）抄進追蹤表。
**會中/會後**（簡報與影音在公司官網 IR 或公開資訊觀測站）依序找四樣東西：
1. 財測指引 vs 上季說法的**變化**（上修/重申/下修/開始迴避）
2. 對「量、價、產品組合」的拆解——營收成長來自出貨量還是漲價？兩者的可持續性完全不同
3. Q&A 段落（比簡報有價值）：管理層**拒答或模糊帶過**的問題，往往就是市場最該擔心的點
4. 資本支出與擴產時程——這是驗證「訂單能見度」最誠實的指標：嘴上樂觀但不擴產 = 不信自己說的話

## 4.2 管理層語言解碼表

| 措辭變化 | 解讀 |
|---|---|
| 「供不應求」→「供需大致平衡」 | 循環可能已過頂，這是最溫和的示警措辭 |
| 「審慎樂觀」→「樂觀」 | 實質上修 |
| 給出具體數字 → 改給「方向性」描述 | 能見度下降 |
| 主動提到競爭對手 | 競爭壓力已實質影響營運 |
| 「長期趨勢不變」 | 通常代表短期有壓（否則不需要強調長期） |

## 4.3 可信度分數（本章的複利所在）

為每家追蹤的公司建一張表：每季記錄「管理層說了什麼 → 下一季實際兌現了嗎」。連續 4~6 季後你會得到市場上極少人有的東西：**這家管理層的財測該打幾折**。保守型公司（常常超越自己的指引）的上修才值得重倉；吹牛型公司的樂觀展望要自動折價。

# 第 5 章｜質化分析與護城河：區分「真受惠」與「題材沾邊」的深度版

## 5.1 護城河五類型與台股電子業對應

| 類型 | 通用定義 | 台股電子業的具體形態 |
|---|---|---|
| 無形資產 | 專利、品牌、特許 | 製程專利、與大客戶的共同開發關係 |
| 轉換成本 | 客戶換供應商很痛 | **認證門檻**（車規/伺服器認證要 1~2 年）、規格綁定（Design-in 後整個產品週期都是你的） |
| 成本優勢 | 同樣東西做得更便宜 | **良率學習曲線**（先進入者的良率領先＝結構性成本優勢）、規模採購 |
| 網路效應 | 用的人越多越好用 | 電子業少見，平台/IP 生意才有 |
| 規模門檻 | 市場只容得下少數玩家 | 利基型設備、特殊材料（市場太小，新進者不划算） |

## 5.2 深度檢核：一檔題材股的五個殺手級問題

1. 該題材產品**現在**佔營收多少 %？（年報產品組合可查；<10% 時股價漲的是想像）
2. 它是**獨供、主供還是二供**？二供的意義是「幫主供壓價」，分到的量與價都差一級。
3. 客戶要換掉它的成本高嗎？（有沒有認證/規格綁定，還是標準品比價格？）
4. 題材兌現時，**產能夠嗎**？沒有產能的訂單題材是空頭支票；查 capex 與擴產公告。
5. 競爭者多快能跟上？（6 個月能跟上的優勢不叫護城河，叫先發時間差）

五題答完，你對「真受惠 vs 概念炒作」的判斷就不再依賴媒體標籤。

# 第 6 章｜進階籌碼與市場結構

前置：手冊一的三大法人與融資已熟悉。本章加三層深度。

## 6.1 分點籌碼（券商分公司進出）

- 是什麼：每檔股票每天由哪些券商分行買賣（證交所「買賣日報表」，玩股網/CMoney 有整理介面）。
- 有效用法：**特定分點長期、持續、單向**買進某中小型股（尤其公司所在地附近的分點）→ 可能是知情資金。
- 無效用法：追逐隔日沖分點的當日買超（他們明天就賣）。先學會辨識知名隔日沖分點名單，把它們的買超從「多方訊號」中剔除。
- 誠實提醒：分點資料噪音極大，只適合當「輔助證據」，永遠不能是買進的主理由。

## 6.2 借券賣出與可轉債（CB）

- **借券賣出餘額**（證交所每日公布）：外資/大戶的放空工具，比融券更能代表法人空方觀點。借券餘額大增 + 股價高檔 = 有人在建立空方部位；但注意 CB 發行公司的借券常是「可轉債套利」的避險腳，不是看空——所以：
- **查 CB**：公司若有流通中的可轉債（公開資訊觀測站），要知道轉換價在哪。股價站上轉換價後的 CB 轉換賣壓、以及 CB 套利者的借券避險，都會扭曲籌碼訊號的解讀。
- 這是進階者與初學者解讀同一份籌碼資料卻得出不同結論的典型場景。

## 6.3 股權分散表的趨勢用法

集保每週公布。看**千張大戶持股比例的 8~12 週趨勢**：
- 股價盤整但大戶比例持續上升 = 吸籌（偏多背離）
- 股價創高但大戶比例下降、400 張以下散戶比例上升 = 派發（偏空背離）
- 單週變化是噪音，趨勢才是訊號。

# 第 7 章｜整合輸出：一份完整的個股研究報告（Buy Case 模板）

深度研究的終點是能寫出這份報告。寫不出來 = 研究還沒完成。

```
【個股研究報告】公司／代碼／日期／現價：

一、一句話論點（電梯簡報）：
   我認為市場低估了 ___，因為 ___，預期 ___ 時會被市場認知。

二、生意本質（第 3、5 章）：
   賣什麼給誰／利潤池位置／護城河類型與強度／五個殺手級問題的答案

三、財務體質（第 1 章）：
   營收動能／毛利率方向／盈餘品質三檢查結果／資產負債表風險

四、估值（第 2 章）：
   使用工具與理由／悲觀-基準-樂觀三情境區間／現價隱含假設 vs 我的判斷

五、催化劑時間表：
   未來 6 個月可驗證事件清單（月營收、法說、產品時程），各附預期

六、可信度紀錄（第 4 章）：
   管理層歷史指引兌現度

七、籌碼狀態（第 6 章）：
   法人／大戶趨勢／CB 與借券的特殊情況

八、否證條件（最重要）：
   出現 ___ 代表論點錯誤，無條件出場

九、部位計畫：
   佔資金 %／分批方式／風險預算
```

# 第 8 章｜12 週進階練習路線

| 週次 | 任務 |
|---|---|
| 1~2 | 挑 3 家你持有或熟悉的公司做盈餘品質三檢查，找出品質最好與最差的一家 |
| 3~4 | 為同 3 家公司畫 PE/PB band，做一次「隱含預期反推」練習 |
| 5~6 | 選一個產業寫一頁產業報告（3.4 模板），完成利潤池分析 |
| 7~8 | 聽 2 場法說會（live 或重播），建立第一份管理層指引追蹤表 |
| 9~10 | 對一檔市場熱門題材股回答五個殺手級問題，判定真受惠或沾邊 |
| 11~12 | 整合產出第一份完整 Buy Case 報告，並請自己一個月後回頭批改 |

**進階期的成功標準**：不是報酬率，而是（1）你的 Buy Case 報告一個月後回看仍站得住腳的比例；（2）你開始能在新聞出來**之前**，從月營收與法說會裡預判到變化。

# 附錄｜常見的深度研究錯誤

1. 研究越深越捨不得賣——深度研究會產生「稟賦效應」，否證條件出現時反而找理由凹單。**研究深度必須配上更嚴格的否證紀律，否則深度是負資產。**
2. 把「公司好」等同「股票好」——好公司在錯誤的價格與循環位置一樣讓你虧錢（回到第 2 章）。
3. 用單一季度數據推翻/確立長期論點——樣本量意識：一季是雜訊，二~三季才是趨勢。
4. 只研究多方證據——每份 Buy Case 強制寫一段「空方會怎麼說」，寫不出有力的空方論述代表你還沒看懂這家公司。
